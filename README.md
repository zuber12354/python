# Python Fundamentals & Git Practice

This repository contains Python helper functions and Git workflow practices.

## Included Code

- `second_largest(numbers)`: Returns the second-largest unique value from a list of floats. Raises a `ValueError` if fewer than two unique numbers are provided.

## Usage Example

```python
from second_largest import second_largest

# Finding second largest
print(second_largest([3, 1, 4, 1, 5]))  # Output: 4
